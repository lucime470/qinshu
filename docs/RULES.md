## 2. 七元甲子

口诀：**一元虚、二元奎、三元毕、四元鬼、五元翼、六元氐、七元箕**。

- 每元 60 天。
- 每一元从甲子日起，按二十八宿顺序逐日排列。
- 元序以七元甲子表直接判定：日柱落在哪一元的六十甲子段，就取该元；同一天干地支在七个元里对应七个不同日禽。
- 判定顺序：先用五虎遁/万年历得日柱，再用“七元甲子表”按日柱反查元序和元内日序，不能只看日柱序号 `(甲子=0…癸亥=59)` 就断言元序。
- 书中示例核对：2021-05-23 辛未日，一元第 8 天，日禽昴日鸡；2022-05-22 乙亥日，七元第 12 天，日禽昴日鸡。两天相隔 364 日，同一日柱在同一元内相差 60 日循环，日禽同为昴日鸡，与两处示例一致。
- 每元第 1 天对应元首禽，第 2 天起顺推。
- 日禽 420 天一个大循环。

示例一（书中第 8–9 页）：

| 日 | 禽 |
|---|---|
| 甲子 | 虚日鼠 |
| 乙丑 | 危月燕 |
| 丙寅 | 室火猪 |
| 丁卯 | 壁水貐 |
| 戊辰 | 奎木狼 |
| 己巳 | 娄金狗 |
| 庚午 | 胃土雉 |
| 辛未 | 昴日鸡 |

示例二（书中第 14 页）：

- 2022-05-22 酉时：七元，乙亥日，日禽昴日鸡。

## 3. 气将

- 每元 60 天分为四段，每段 15 天。
- 气将取每元第 1、16、31、46 天对应的星宿。
- 每元四个气将，七元共二十八个，对应二十八宿。
- 起翻禽时，从当前时辰地支起气将，顺数地支、顺数二十八宿，数到时禽；再从该处逆数地支、顺数星宿，回到时辰，所得即翻禽。

书中示例（2022-05-22 酉时）：

- 气将：箕水豹。
- 时禽：觜火猴。
- 日禽：昴日鸡。
- 翻禽：心月狐。

```

```

逆回：

卯（翼）寅（轸）丑（角）子（亢）亥（氐）戌（房）酉（心）

## 4. 倒将

- 从时辰起时禽，顺数地支、顺数二十八宿，数到翻禽所在；再逆数地支、顺数星宿，回到时辰，所得即倒将。
- “进多少步，退多少步”与翻禽一致。

书中示例（2022-05-22 酉时）：

- 时禽：觜火猴。
- 翻禽：心月狐。
- 倒将：昴日鸡。

## 5. 活曜

诀：**日毕月尾金牛头，木虚水氐火奎流，土翼常将寅上转，此是番禽活曜头。**

- 先看时禽的七曜属性。
- 不管属性，都从地支寅起排。
- 日宿起毕，月宿起尾，金宿起牛，木宿起虚，水宿起氐，火宿起奎，土宿起翼。
- 顺数地支、顺数二十八宿到时禽，再顺数回去，落到时辰所属地支，即为活曜。

书中示例（2022-05-24 巳时）：

- 时禽：危月燕（月宿，起尾）。
- 顺数：寅（尾）丑（箕）子（斗）亥（牛）戌（女）酉（虚）申（危）。
- 顺回：申（危）酉（室）戌（壁）亥（奎）子（娄）丑（胃）寅（昴）卯（毕）辰（觜）巳（参）。
- 活曜：参水猿。

## 6. 日禽、时禽与昼夜

### 6.1 时禽起法（已核对书页）

口诀（书中第 13 页）：

> 七曜禽星会者稀，日虚月鬼火从箕，水毕木氐金奎位，土宿还从翼上推，常将日禽寻时禽，即从日禽寻时禽。

起法：

1. 先确定日禽的七曜属性。
2. 从子时开始，按该属性对应的起始宿排十二时辰。
3. 起始宿：日宿起虚、月宿起鬼、火宿起箕、水宿起毕、木宿起氐、金宿起奎、土宿起翼。
4. 子、丑、寅……亥依次顺推二十八宿。
5. 时禽表见书中第 13 页。表头“七元时禽”只是题名；表体按日、月、火、水、木、金、土七曜分行，每行只改变子时起宿，不再按元分表。跨元时只要日禽七曜不变，时禽算法不变。

书中例：2022-05-22 酉时，日禽昴日鸡（日宿），子时起虚，酉时为觜火猴。

> 注意：这与活曜“日毕月尾金牛头”的起宿不同。时禽用“日虚月鬼火箕”，活曜用“日毕月尾金牛头”。两处不可混用。

### 8.3.1 得地（由外锁泊吉凶折算）

书中反复使用“得地/不得地”，但没有另列一套独立的五行旺衰公式。当前采用可追溯的保守口径：

- 外锁泊吉凶为 **吉、贵、不妨** → `得地`。
- 外锁泊吉凶为 **凶、忌** → `不得地`。
- 该宫此禽未明列吉凶（如草宫“余禽有得失”）→ `原文未定吉凶`，不判为得地或不得地。

`core/relations.py::de_di()` 输出 `status`、`matched`、`label`、`column`、`text` 和出处；结果同时挂在：

- `relations.suo_bo_facts.outer[*].de_di`（各禽）
- `relations.suo_bo_facts.de_di[*]`（按盘面禽星键汇总）

此字段只表示“原文标签是否属于吉类”，不自动推断变化、吞啖或最终吉凶。出战、求官、擒捕、声息等占类按原文条件引用该事实。
