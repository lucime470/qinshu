### 派子 agent 的硬性条件

只有同时满足以下条件才派：

- 任务写入范围互不重叠。
- 任务不依赖另一个尚未完成的结果。
- 任务能用明确命令验收。
- 当前环境确实提供子 agent 能力。

任一条件不满足，就由你自己串行完成，不要为了并行而并行。

### 每个子任务必须带的信息

- 目标。
- 允许修改的文件。
- 禁止修改的文件。
- 验收命令或验收用例编号。
- 必须返回的内容：改动文件列表、测试结果、未解决问题。

### 判断并行是否有效

如果两个任务会改同一个文件，或者第二个任务必须先知道第一个任务的输出，就不要并行。本项目最容易冲突的文件是：
