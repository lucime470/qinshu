## 1. 项目目标

做一个本地运行的演禽起课器，完成三件事：

1. **准确排盘**：由公历时间生成四柱、七元、日禽、时禽、气将、翻禽、倒将、活曜，以及锁泊、飞伏、合冲等盘面关系。
2. **引导式核对**：按固定流程逐项展示盘面事实、书中依据与候选象义，不替用户下吉凶结论。
3. **课例留存**：在本地保存课例，可按条件检索、查看、编辑判断和备注、删除。

产品定位是**排盘 + 交互式引导分析，人作最终判断**。不做自由对话问答，也不自动生成断课结论。

## 4. 规则基线

### 4.1 资料来源

主资料：

- `演禽正传—玄阳.pdf`：67 页，起例、七元、时禽、翻禽、倒将、活曜、锁泊、飞伏、禽性与分类占法。
- `含演禽格局-禽星易见-明-池本理.txt`：原为 GBK 编码，已转为 `禽星易见_utf8.txt`，用于原文占法和四库提要依据。

辅助资料：

- `演禽起课仅供参考--玄阳.docx`：可作为同一作者体系的交叉核对，不作为主基准。
- `《太古演禽》黑白版38页.葛氏啸园藏版.pdf`、`演禽简引.pdf`、`二十八宿算走失(1).pdf`：后续扩展或专项核对资料，不进入第一版主规则。
- 《禽星辑要》：仅有纸质版，暂不作为第一版规则来源，待后续按页补录。

### 4.2 规则优先级

1. 《演禽正传》的起课、排盘和用神定义。
2. 《禽星易见》的原文占法，用于补充和并列展示。
3. 两者冲突时，主界面以《演禽正传》为准，同时显示《禽星易见》原文与差异说明。
4. 所有规则条目必须能追溯到具体书名、章节或页码。
5. 无出处的内容不得进入“原文断语”区，只能作为明确标注的“待核资料”。

### 4.3 起课链条

```
公历时间
→ 四柱（年、月、日、时）
→ 节气月建（月柱）
→ 子初换日（日柱）
→ 七元甲子
→ 日禽
→ 时禽
→ 气将
→ 翻禽
→ 倒将
→ 活曜
→ 锁泊、飞伏、合冲、三合等关系
```

其中：

- 七元口诀：一元虚、二元奎、三元毕、四元鬼、五元翼、六元氐、七元箕。
- 日禽以 420 天为一个大循环，每元 60 天。
- 气将以每元第 1、16、31、46 天所对应的星宿为准。
- 翻禽：从时辰地支起气将，顺数地支与二十八宿到时禽，再逆数地支、顺数星宿回时辰。
- 倒将：从时辰起时禽，顺数到翻禽，再逆数回时辰。
- 活曜：按时禽七曜属性起诀，从寅位起排；诀为“日毕月尾金牛头，木虚水氐火奎流，土翼常将寅上转，此是番禽活曜头”。
- 具体步进与边界必须以《演禽正传》第 16–24 页原文和书中示例为准。

### 4.4 已知需重点核对的点

- 《演禽正传》示例中的“翻禽/翻将”“倒将”术语与《禽星易见》的“番禽/到将”存在对应关系，界面需统一名称并保留原书称谓。
- 活曜口诀在不同版本中可能写作“火奎”或“火箕”，必须以《演禽正传》正文和示例表为准。
- 书中示例存在个别星宿名异体字，例如“壁水貐/壁水狳”“翼火蛇/翌火蛇”，数据层应统一标准名并保留原文异体。
- 七元起点、甲子日对应的元序、子初换日与节气交接时刻，必须通过示例与边界测试固定，不得凭经验补全。

## 5. 盘面模型

### 5.1 基础盘面字段

- 公历时间与时区。
- 四柱：年柱、月柱、日柱、时柱。
- 节气与月建。
- 七元序号与元名。
- 日禽、时禽、气将、翻禽、倒将、活曜。
- 彼我标识：翻禽为我，倒将为他；原书如有不同称谓，保留对照。
- 十二宫位置。
- 二十八宿分布。
- 锁泊宫位与吉凶属性。
- 飞伏状态。
- 昼夜状态。
- 合、冲、三合、生克、吞啖等关系。
- 真太阳时对照盘及其差异标记。

### 5.2 展示分区

- **起课信息**：时间、四柱、七元、节气。
- **核心禽星**：日禽、时禽、气将、翻禽、倒将、活曜。
- **彼我关系**：我禽、他禽、强弱与生克。
- **宫位关系**：十二宫、锁泊、飞伏、合冲、三合。
- **占类对照**：用神分配、原文断语、适用条件、用户判断。
- **证据与出处**：书名、章节、页码、原文。
- **课例操作**：保存、编辑、删除、导出预留。

## 6. 占类与断语规则

### 6.1 占类来源

第一版覆盖：

- 《禽星易见》分类占法：婚姻、求财、患病、出战、谒见会人、逃难、捕逃、失物等。
- 《演禽正传》分类占法：射覆、家宅、婚姻、求医问药、求官赴举、求财得物、交易成败、博弈胜负、失物存亡、饮食宴会、年岁丰欠、孕产生男生女等。

两书占类名称不完全一致，数据层应建立统一占类编码，并保留原书章节名。

### 6.2 用神分配示例

| 占类 | 《演禽正传》用神 | 《禽星易见》用神 | 处理 |
|---|---|---|---|
| 婚姻 | 番禽为男，时禽为女；男家问婚时时禽为男、番禽为女；女家问婚时番禽为男、时禽为女；日禽为媒人 | 番禽为男家，到将为女家，日禽为媒人 | 以《演禽正传》为主，并列原文与差异 |
| 求财 | 时禽宜旺相；空手求财以番禽旺相克时禽为佳 | 番禽为求财人，到将为出财人，日禽为财与牙保 | 标注用神差异，不合并结论 |
| 疾病 | 时禽为病人，番禽为病症，日禽为医药 | 番禽为病人，到将为病症，日禽为医人 | 并列显示，提示不可混用 |
| 失物 | 番禽为所失之物，时禽为失物之主，日禽为藏处 | 我禽为失物之主，他禽为所失之物，日禽为藏处 | 以《演禽正传》为主，保留原书对照 |

### 6.3 断语记录结构

每条断语至少包含：

- `source_book`：书名。
- `source_chapter`：章节名。
- `source_page`：页码或原文位置。
- `category`：统一占类编码。
- `role_map`：用神分配。
- `condition`：触发条件，结构化表达。
- `original_text`：原文。
- `interpretation`：必要的白话解释，可留空。
- `priority`：主基准或辅助。
- `conflict_group`：与其他版本冲突时的分组标识。

界面只展示“命中条件”的原文，未命中条件的内容放入可展开的“全部相关原文”，不得混入主判断区。

## 7. 交互流程

### 7.1 起课

1. 打开应用，默认填入当前时间。
2. 用户可改为指定时间。
3. 可选输入经度，生成真太阳时对照盘。
4. 点击“起课”，生成盘面。
5. 显示四柱、七元、核心禽星和盘面关系。

### 7.2 固定引导

按以下顺序逐项检查：

1. 时间与四柱核对。
2. 七元与日禽核对。
3. 时禽与气将核对。
4. 翻禽、倒将、活曜核对。
5. 彼我强弱与生克。
6. 飞伏与昼夜。
7. 合、冲、三合。
8. 锁泊与宫位。
9. 选择占类，显示用神分配与相关原文。
10. 用户填写判断、依据和备注。

每一步包含：

- 盘面事实。
- 规则出处。
- 候选象义，仅限书中有对应者。
- 待用户判断的问题或空白判断栏。

### 7.3 盘面点击

- 点击某只禽：高亮其宫位、合冲对象、彼我关系；右侧显示该禽信息卡。
- 点击某宫位：高亮该宫锁泊禽星与相关关系；右侧显示宫位说明和书中断诀。
- 点击占类断语：展开原文、出处、适用条件和冲突版本。

### 7.4 课例

- 保存时记录输入时间、四柱、盘面快照、所选占类、逐步判断、备注。
- 列表支持按时间、占类、关键词检索。
- 支持查看、继续编辑判断、删除。
- 删除需二次确认；删除只移除本地课例记录，不影响书籍资料。

## 11. 风险与待确认项

1. **历法库与书中口径不一致**：以书中示例和边界用例回归为准，必要时在历法层做显式校正。
2. **七元起点存在版本差异**：必须用书中完整示例锁定，不可只凭歌诀。
3. **活曜起法口诀异文**：需对照《演禽正传》正文和示例表确认“火奎/火箕”等字。
4. **两书用神冲突**：已定为主基准优先、并列差异，但具体占类仍需逐条校对。
5. **占类覆盖量大**：第一版可先完成数据结构与全部占类入口，再按原文完整性分批填充断语。
6. **《禽星辑要》未电子化**：不阻塞第一版；后续如需补录，按卷上起课页优先拍照或扫描。
7. **真太阳时对照盘**：仅作参考，不改变主盘和断课用神。
