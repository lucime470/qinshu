# 禽枢 Qinshu

输入一个时间，排出完整的演禽盘。

演禽起课的链条不短：四柱、七元、日禽、时禽、气将、翻禽、倒将、活曜，再往外是内外锁泊、合冲三合、飞伏和四时旺衰。这个工具把这些一次排完，把每一步落在哪一宫、依据哪条原文摆出来。它不替你判断吉凶，也不生成断语，结论留给你自己写。

当前版本：**1.0.0**

## 功能

- 起课：按北京时间排盘，子初 23:00 换日，节气定月。可填经度，另排一张真太阳时对照盘，主盘不受影响。
- 十二宫圆盘：六类禽星同盘显示，点击禽星或宫位，右侧联动详情。
- 锁泊圆盘：地支、内锁泊、外锁泊三层同心环，六类禽星随时切换。
- 生克关系：翻禽与倒将的生克用箭头标出，附带本宫、旺衰和得地；三合与时禽刑害同区列出。
- 盘面核对表：六类禽星的七曜、本宫、昼夜、飞伏、外锁泊、吉凶、得地、旺衰、合冲逐行对照。
- 占类对照：22 类占法，先列用神分配，再列命中条件、原文和两书差异。
- 课例：本地保存判断与备注，可按关键词、占类、起止日期检索，也能载入、修改、删除。

## 环境要求

- Windows 10 / 11
- Python 3.10 或更高（开发环境是 3.14）

依赖只有四个：`lunar_python`、`Jinja2`、`tzdata`、`pytest`。`tzdata` 不能省，Windows 上缺了它，`ZoneInfo("Asia/Shanghai")` 会直接报错。

## 安装与启动

最省事的方式是双击仓库根目录的 `start.bat`。它会自己建虚拟环境、装依赖、启动服务，然后打开浏览器。

手动启动：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

默认地址是 `http://127.0.0.1:8770/`。端口被占用时会往后顺延，以终端里打印的地址为准。

## 开始使用

1. 起课时间默认取当前时间，也可以改成任意时刻。需要真太阳时对照时再填经度。
2. 点「起课」。盘面、卡片和详情会一起刷新。
3. 点圆盘里的禽星，右侧显示它的五行、阴阳、宫位、合冲、外锁泊、吉凶、得地、刑害与禽性原文。点宫位则看这一宫落了哪些禽。
4. 在锁泊圆盘上方切换日禽、时禽、翻禽、倒将、气将、活曜，外锁泊一圈会跟着换，地支和内锁泊固定不动。
5. 选一个占类，点「查看」。用神、命中条件和原文会分块列出，两书说法不同的地方会单独标出。
6. 写完判断和备注，点「保存当前课例」。数据存在本机的 `storage/qinshu.db`。

## 口径与边界

- 主基准是《演禽正传》，辅助基准是《禽星易见》。两者冲突时以《演禽正传》为主，页面并列显示差异。
- 只做「时间 → 盘面」，不做盘面反查时间。
- 所有盘面事实由后端计算，前端只负责显示和联动。
- 系统不自动给吉凶结论。占类区列的是用神、条件和原文，判断由人来写。
- 课例只存在本机，没有账号体系，也不会上传。
- 原书 PDF、DOCX 不入库。`data/raw/` 只放纯文本提取件，用于核对页码和原文。
- 仍有几条待核：水宫「走兽凶」的具体禽星名单、「心奎二宿百般寻」所指宫位、活曜口诀的异文。这些在 `docs/RULES.md` 里有记录，没有当作确定规则使用。

## API

页面用到的接口都在本机：

| 方法 | 路径 | 作用 |
|---|---|---|
| `POST` | `/api/chart` | 由时间生成盘面 |
| `GET` | `/api/birds` | 二十八宿资料与锁泊圆盘对应 |
| `GET` | `/api/categories` | 占类列表 |
| `POST` | `/api/reading` | 生成占类对照 |
| `GET` | `/api/lessons` | 课例列表与检索 |
| `POST` | `/api/lessons` | 保存课例 |
| `GET` | `/api/lessons/{id}` | 读取课例 |
| `PATCH` | `/api/lessons/{id}` | 修改判断、备注与占类 |
| `DELETE` | `/api/lessons/{id}` | 删除课例 |
