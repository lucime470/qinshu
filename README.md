# 禽枢

演禽起课器，跑在本机浏览器里。输入一个时间，它把整张盘排出来。

演禽起课的步骤不少：四柱、七元、日禽、时禽、气将、翻禽、倒将、活曜，再往外是内外锁泊、合冲、三合、飞伏和四时旺衰。前后是串起来的，前面错一步，后面全跟着歪。禽枢把这些一次算完，再把每个结果落在哪一宫、依据哪段原文一并摆出来，方便你自己核对。

它不写断语，也不替你判吉凶。占类区只放用神、命中条件和原文；两本书说法不一样时，就并排放在那里。结论由人写。

当前版本 1.0.0。

## 页面上有什么

起课后，页面从上到下大致是这样几块。

最上面是十二宫圆盘，六类禽星都在同一张盘上。点禽星看它的五行、阴阳、本宫、合冲、外锁泊、吉凶、得地、刑害和禽性原文；点宫位，则看这一宫落了哪些禽。

往下是锁泊圆盘。三层同心环，由内到外是地支、内锁泊、外锁泊，切换上方的日禽／时禽／翻禽／倒将／气将／活曜，只有外锁泊一圈会变，地支和内锁泊不动。

再往下是生克关系。翻禽和倒将谁生谁克，用箭头画出来，节点里带本宫、旺衰和得地。三合判定和时禽刑害放在同区的右侧，不另开板块。

盘面核对表把六类禽星的七曜、本宫、昼夜、飞伏、外锁泊、吉凶、得地、旺衰、合冲逐行列齐。想把整盘快速过一遍，看这张表比逐个点卡片省事。

最下面是占类对照和课例。22 类占法，先列用神，再列命中的条件和原文，两书有出入的地方会单独标出。判断和备注可以存成本地课例，之后按关键词、占类或日期范围找回来。

## 跑起来

需要 Windows 10／11，Python 3.10 以上。开发时用的是 3.14。

最省事的是双击根目录的 `start.bat`。它会建虚拟环境、装依赖、启动服务，再打开浏览器。想手动来也行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

默认开在 `http://127.0.0.1:8770/`。这个端口被占用时会自动往后找，具体地址以终端打印的为准。

依赖只有 `lunar_python`、`Jinja2`、`tzdata` 和 `pytest`。`tzdata` 别漏装：Windows 上没有它，`ZoneInfo("Asia/Shanghai")` 会直接抛 `ZoneInfoNotFoundError`，服务起不来。

## 起课口径

- 一律按北京时间。子初 23:00 换日，节气定月。
- 经度是可选项，只用来另排一张真太阳时对照盘。主盘和断课用神不看经度。
- 主基准是《演禽正传》，辅助基准是《禽星易见》。两边冲突时以《演禽正传》为准，页面并列显示差异。
- 只支持“时间到盘面”，不做盘面反查时间。
- 盘面事实全部由后端算，前端只负责显示和联动。

还有几处没定下来，都记在 `docs/RULES.md` 里：水宫“走兽凶”的禽星名单、“心奎二宿百般寻”具体指哪一宫、活曜口诀的异文。这几条没有当成确定规则写进判断。

## 数据放在哪

课例存在本机的 `storage/qinshu.db`，不上传，也没有账号体系。

仓库里不带原书 PDF 和 DOCX。`data/raw/` 只有两份纯文本提取件，用来核对页码和原文；`data/rules/` 是从原文整理出的禽星、七元、锁泊和占类规则。

## 目录

```
qinshu/
├─ app.py         启动入口
├─ start.bat      双击启动：建环境、装依赖、开浏览器
├─ core/          历法、七元、时禽、气将、翻禽、倒将、活曜、关系、占类
├─ data/
│  ├─ rules/      规则表
│  └─ raw/        古籍纯文本提取件
├─ webapp/        页面、静态资源、本地 HTTP 接口
├─ storage/       SQLite 课例库
├─ tests/         书中示例、历法边界、关系、占类、接口
└─ docs/          项目、规则、数据模型、验收、交接
```

## 接口

页面用到的接口都只监听本机。

| 方法 | 路径 | 作用 |
|---|---|---|
| `POST` | `/api/chart` | 由时间生成盘面 |
| `GET` | `/api/birds` | 二十八宿资料与锁泊圆盘对应 |
| `GET` | `/api/categories` | 占类列表 |
| `POST` | `/api/reading` | 生成占类对照 |
| `GET` | `/api/lessons` | 课例列表与检索 |
| `POST` | `/api/lessons` | 保存课例 |
| `GET` | `/api/lessons/{id}` | 读取课例 |
| `PATCH` | `/api/lessons/{id}` | 修改判断、备注与占类 |
| `DELETE` | `/api/lessons/{id}` | 删除课例 |
